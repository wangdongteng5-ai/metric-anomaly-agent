# 口径文档（M2）

> 机器版：`code\project\metrics.yaml`（代码按它拼 SQL）｜本文是中文说明版，M6 放进 RAG 供 Agent 检索引用
> 数据：84.51° The Complete Journey 2.0（美国连锁超市）｜业务说法按国内即时零售：门店 ≈ 前置仓，家庭 ≈ 用户，购物篮 ≈ 订单｜更新：2026-10-07（M3）

## 一、通用口径

| 项 | 口径 |
|---|---|
| 有效销售行 | 数量 > 0 且金额 > 0 的交易行；其余（约 0.8%，退货、赠品等）不计入任何指标 |
| 时间粒度 | 自然周，周一为一周的第一天，用该周周一的日期表示，例如「2017-06-05 周」 |
| 有效周范围 | 2017-01-02 周 ～ 2017-12-25 周，共 52 周。首尾两周各只有 1 天，已去掉 |
| 节假日 | 只收 2 周：**2017-12-18 周**（圣诞前采购周，含 12-24，GMV 环比 +31.6%）、**2017-12-25 周**（圣诞周，圣诞节当天无交易、只有 6 天，环比 −31.4%）。其他美国节日数据上无明显影响，不计入 |
| 已知周期：月初效应 | 包含每月 1 号的周，GMV 通常环比上涨（2017 年 11 个这样的周中 10 个上涨，平均约 +9%）；**月初后一周常回落 −9%～−11%**。判断下跌时先看上一周是不是月初周（基数偏高） |
| 货币 | 美元 |

## 二、指标

### GMV
- **定义**：有效销售行的销售金额（`sales_value`）之和
- **注意**：`sales_value` 是零售商实际收到的金额；折扣单独记在「折扣金额」里，不从 GMV 中再扣
- **常见问题**：GMV 含不含退货？不含，退货行不是有效销售行

### 订单数
- **定义**：有效销售行的购物篮（`basket_id`）去重计数
- **注意**：一个购物篮 = 一次结账

### 客单价
- **定义**：GMV ÷ 订单数
- **拆解关系**：GMV = 订单数 × 客单价，诊断时先按这个公式判断是「单量跌」还是「单价跌」

### 折扣金额
- **定义**：零售折扣（`retail_disc`）+ 优惠券折扣（`coupon_disc`）+ 优惠券匹配折扣（`coupon_match_disc`）之和
- **注意**：数据中三项均为正数，表示让利的金额

### 户均 GMV
- **定义**：GMV ÷ 活跃家庭数（M3 新增；2017-06-05 周 = 68.33 美元）
- **拆解关系**：GMV = 活跃家庭数 × 户均 GMV，用来判断是"人少了"还是"每人花得少了"

### 活跃家庭数
- **定义**：本周有过至少一次有效购物的家庭去重计数

### 周留存率
- **定义**：上周活跃的家庭中，本周仍有购物的家庭占比
- **参考值**：52 周中位数约 72%
- **为什么不用「复购率」**：「本周活跃家庭中以前买过的占比」在超市场景下几乎恒为 100%，无法反映变化

### 流失家庭数
- **定义**：截至本周周一，最近一次有效购物距今超过 **28 天**的家庭数
- **为什么是 28 天**：相邻两次购物间隔的 95% 分位是 21 天、99% 分位是 51 天；28 天超过 95% 的正常间隔，又正好是 4 周，和周口径对齐

## 三、维度

| 维度 | 取值 | 规则 | 注意 |
|---|---|---|---|
| 门店分组 | 头部 / 腰部 / 长尾 | 按全年 GMV 排名：前 20 家为头部（约 33% GMV），第 21～100 家为腰部（约 63%），其余 357 家为长尾（约 4%） | 排名按全年计算，各周的分组保持不变 |
| 品类 | GROCERY、DRUG GM、PRODUCE、MEAT 等 32 个 | 商品表自带的部门（department） | 品类名在报告中翻译成中文；GROCERY 占 50.5% |
| 细分品类 | BEEF、SOFT DRINKS 等 303 个 | 商品表自带的二级品类（product_category），在品类之下 | 单个最大约 4%；用于在某个品类内部继续下钻 |
| 主力门店（M3 第 6 步实现） | 头部 / 腰部 / 长尾 | 用户全年花钱最多的门店分组，是**用户属性** | 门店无地理信息，每店只有 55～213 户，门店问题按"主力门店为某组的用户"分析 |
| 新老客 | 新客 / 老客 | 首次购物在本周的家庭为新客 | **2017-02-06 周起才可用**：数据从 2017-01-01 开始，前 5 周新客占比虚高（从 85% 逐步降到 5%）；新客每周约 5 户、只占 GMV 0.2%，不能解释 GMV 的明显变化 |
| 年龄段 | 34 岁及以下 / 35-54 岁 / 55 岁及以上 | 原始 6 档合并为 3 档，每档每周活跃家庭 ≥ 100 | 只覆盖 801 户（32%）；无画像的家庭不参与该维度 |
| 收入段 | 低（<35K）/ 中（35-74K）/ 高（75K+） | 原始 12 档合并为 3 档 | 同上，只覆盖 32% 的家庭 |
| RFM 分层 | 待 M4 定 | 按本周周一之前的最近购物时间、频次、金额计算 | 依赖时间点，在工具里实现 |

## 四、使用规则（Agent 必须遵守）

1. 只能使用本文档列出的指标和维度；不在列表中的（例如 DAU），回答「不支持该指标」，不要用相近指标代替
2. 周必须是有效周范围内的具体周一日期；超出范围时，告知可查询的范围
3. 使用画像维度（年龄段、收入段）时，必须说明「只覆盖 32% 的家庭」
4. 2017-02-06 周之前不使用新老客维度
5. 报告中的每个数字都必须来自工具的返回结果，不允许自行估算
